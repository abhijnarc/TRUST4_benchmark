# Graph-TRUST4-pure

This is an isolated experimental assembler. It does not modify or reuse the existing Graph-TRUST4 implementations.

Assembly graph construction validates variable-length overlaps with sequence identity and Phred-aware QAOS. Candidate paths are generated by bounded simple-path enumeration over connected components; no edge is selected greedily during assembly and alternatives remain represented as paths. Each emitted path records ordered nodes, edges, edge measurements, branch status, and bundle provenance.

The fixed FZ-116 candidate FASTQs are used unchanged. Defaults are k=9, minimum overlap 31, minimum identity 0.90, minimum QAOS 0.90, Q_HIGH 20, candidate cap 500, posting cap 1000, 64 OpenMP threads, 32 GB memory target, and batch size 10000.
